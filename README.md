# Pocket Playground

Free, safe mini-games for little learners (ages 3-7).

- **Balloon Pop** - pop the right letter or number
- **Memory Match** - 3 levels of animal pairs
- **Count Fun** - tap to count, then pick the number
- **Copy Colors** - watch and repeat the colour tune

Win stars to unlock stickers. Works offline and can be added to a phone home screen.

No ads, no login, no tracking. Progress (stars) is saved only on the child's own device.
